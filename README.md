# 星海2 密技面板 sc2-cheat-panel

[English](README.en.md)

玩《星海爭霸II》劇情時，點一下按鈕或在遊戲裡按熱鍵，就自動輸入密技，不用每次查、自己打。

- 23 個官方密技全收錄，分類列出，附中文說明與適用範圍。
- 常用的 5 個預設綁好熱鍵（`Ctrl+Alt+1`～`5`），任何密技都能自訂熱鍵。
- 面板可以永遠在最上層；點按鈕會自動切回遊戲再輸入。
- 零第三方套件：只用 Python 內建的 tkinter 和 Windows 內建 API。

> ⚠️ **用了密技，這個劇情存檔之後就拿不到成就**（播歌的彩蛋 `OverEngineeredCodPiece` 除外），要開新劇情或讀取第一次用密技之前的存檔才會恢復。想拿成就就別用。

## 適用版本

| 項目 | 版本 |
|---|---|
| 作業系統 | Windows 10 / 11（64 位元；實測 Windows 10 Home 22H2，build 19045） |
| Python | 3.10 以上（實測 3.12.10），需含 tkinter（官方安裝檔預設就有） |
| 星海爭霸II | 實測客戶端 5.0.16（build 97563）。密技是遊戲本身的功能，多年沒有變過 |

## 使用方式

1. 雙擊 `Run.bat`（不會跳出黑色視窗）。
2. 進入劇情任務。**遊戲建議設成「視窗化（全螢幕）」**：點面板按鈕時要切換視窗，獨佔全螢幕切換會卡頓或閃黑。
3. 兩種用法：
   - **熱鍵**：在遊戲裡直接按，例如 `Ctrl+Alt+1` 無敵。按完放開，工具會等你放開 Ctrl/Alt 才開始輸入。
   - **點按鈕**：工具會自動切回遊戲、按 Enter、打密技、再按 Enter。
4. 點某個密技右邊的「Ctrl+Alt+1」或「＋設定熱鍵」就能改熱鍵。至少要兩個修飾鍵（例如 Ctrl+Alt），因為遊戲本身用 `Ctrl+數字` 編隊、`Shift+數字` 加入編隊。

### 預設熱鍵

| 熱鍵 | 密技 | 效果 |
|---|---|---|
| `Ctrl+Alt+1` | TerribleTerribleDamage | 無敵（再輸入一次關閉） |
| `Ctrl+Alt+2` | WhoRunBartertown | 晶礦、瓦斯各 +5000 |
| `Ctrl+Alt+3` | CatFoodForPrawnGuns | 快速建造、升級 |
| `Ctrl+Alt+4` | Bunker55AliveInside | 無人口上限 |
| `Ctrl+Alt+5` | TookTheRedPill | 全開地圖 |

其他 18 個在面板上點，也可以自己綁熱鍵。「直接失敗」（`LetsJustBugOutAndCallItEven`）只能用點的，而且會先問你確定嗎。

### 劇情畫面用的密技

「點數 +500 萬」「開啟所有任務」「開啟所有研究」「開啟所有過場動畫」「開啟所有新聞」要在**艦橋／劇情畫面**輸入，不是在任務中，而且主要適用《自由之翼》（其中點數和新聞在《蟲族之心》無效）。

## 安全設計

- **只打進星海2**：用熱鍵時，如果目前視窗不是星海2（例如你正在 LINE 打字），工具不會送出任何按鍵。辨識方式是看視窗背後的程式（`SC2_x64.exe`），不是看標題，所以不會打進 Battle.net 啟動器或地圖編輯器。
- **不經過輸入法**：預設用 Unicode 方式送字，注音輸入法開著也不會把密技變成注音。萬一遊戲不吃這種輸入，底下「輸入方式」可以改成「模擬實體按鍵」（這種會受輸入法影響，要先切成英文）。
- **不做自動操作**：這個工具只負責輸入官方密技，不做自動下兵、自動施法這類腳本。

## 想拿成就又常失敗？（不用密技的正規輔助）

- **調慢遊戲速度**：單人劇情可以在「選項 → 遊戲」把速度調成較慢，反應時間多很多。成就是否受速度影響以遊戲顯示為準。
- **任務中途存檔**：大波進攻前存一次，失敗就讀檔重打那一波。
- **先查攻略**：Liquipedia 等網站有各關殘酷難度的打法（敵人從哪來、幾分鐘來大波）。
- **分開拿**：先用低難度拿關卡挑戰成就，再專心拚殘酷通關。

## 檔案

| 檔案 | 用途 |
|---|---|
| `app.py` | 面板介面 |
| `cheats.py` | 密技清單與中文說明（來源見檔案開頭） |
| `winput.py` | 找遊戲視窗、切換視窗、送按鍵（Windows API，ctypes） |
| `hotkeys.py` | 全域熱鍵（背景執行緒）與熱鍵規則 |
| `config.py` | 讀寫 `settings.json` |
| `Run.bat` | 啟動（無主控台視窗） |
| `tests/` | 單元測試：`python -m unittest discover -s tests` |
| `scripts/selftest.py` | 不用遊戲的實機檢查：實際打字進輸入框、實際觸發熱鍵（會搶焦點幾秒） |

## 設定檔與還原

- 設定存在程式旁邊的 `settings.json`（熱鍵、置頂、輸入方式）。**刪掉它就回到預設值**。
- 設定檔壞掉時，程式會把它改名成 `settings.json.bad` 保留，然後用預設值啟動，不會打不開。
- 這個工具不改任何系統設定、不寫登錄檔、不改遊戲檔案。關掉面板，熱鍵就全部釋放。

## 搬到其他電腦（可攜性注意事項）

- **要先裝 Python 3.10 以上**，安裝時勾選「Add python.exe to PATH」。沒裝的話 `Run.bat` 會提示你。
- 整個資料夾複製過去就能用；`settings.json` 一起複製就會保留你的熱鍵。
- **星海2 若用「系統管理員身分」執行，這個工具也要用系統管理員身分開**，否則 Windows 會擋下輸入（面板會顯示提示）。
- 熱鍵如果被別的程式（錄影軟體、Discord 等）先占用，面板會列出哪幾個沒生效，換一組就好。
- 只支援 Windows。星海2 的 macOS 版無法使用。

## 已知限制

- 密技效果（例如「再輸入一次關閉」）以遊戲實際行為為準；各部劇情的支援差異參考 Blizzard 官方與媒體整理，未逐一實測。
- 獨佔全螢幕模式下點面板按鈕可能切換不順；用熱鍵不受影響。
